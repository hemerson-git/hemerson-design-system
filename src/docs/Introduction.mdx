# Hemerson Design System

Dark-first and quiet, with one sage-teal accent. Content sits on solid surfaces; the controls and navigation that float above it are made of liquid glass.

Use the toolbar to switch between the **dark** and **light** themes, and to turn on **reduced transparency**, which makes every glass surface solid.

## Principles

- **Dark is home.** Design in dark first; light is its daylight counterpart, not an inversion. Projects open in dark whatever the system setting; light is the visitor's choice, through a toggle that remembers it.
- **One accent.** The sage teal carries every primary action, link and selection.
- **Glass floats, content doesn't.** Glass is for bars, sidebars, menus, dialogs, toasts and floating buttons. Cards, tables and forms are solid.
- **Never glass on glass.** A selected item inside a glass bar uses a soft tint, not a second glass layer.
- **Glass you can see through.** Like Apple's Liquid Glass: a light tint, a light blur, a lit rim and, in Chromium, a lens that bends the content at the edges. Text on regular glass keeps 4.5:1 over mid-grey content; over much brighter imagery in the dark theme (or darker in the light one), give the glass the other theme with `data-theme`. Dialogs use thick glass: also see-through, with more blur and tint, so forms stay legible over the app's own page. Tables can sit on glass too, with `glass`.
- **Legible everywhere else.** Every text color meets 4.5:1 on every surface in both themes.
- **Numbers are mono.** Amounts, codes and section indices use JetBrains Mono with tabular figures.

## Using the package

```bash
npm install @hemerson/design-system
```

```tsx
import "@hemerson/design-system/styles.css";
import { Button } from "@hemerson/design-system";

export function Toolbar() {
  return <Button variant="primary">Novo boleto</Button>;
}
```

Apps open in the dark theme. Restore the visitor's last choice before the first render, and let them change it with the toggles:

```ts
// main.tsx, before the first render, so the page never flashes the wrong theme
import { applyStoredAppearance } from "@hemerson/design-system/appearance";

applyStoredAppearance();
```

```tsx
import { ThemeToggle, TransparencyToggle } from "@hemerson/design-system";

<ThemeToggle />          // dark ↔ light, remembered
<TransparencyToggle />   // solid glass, remembered
```

Raise toasts from anywhere once the app sits inside `ToastProvider`:

```tsx
import { ToastProvider, useToast } from "@hemerson/design-system";

<ToastProvider>
  <App />
</ToastProvider>;

// anywhere inside
const toast = useToast();
toast.success("Boleto salvo", "Fulano de Tal · R$ 1.234,56");
toast.error("Não foi possível salvar");
```

Turn on the edge lens once at startup. It only acts in Chromium; elsewhere glass stays frosted:

```ts
import { enableGlassRefraction } from "@hemerson/design-system/glass";

enableGlassRefraction();
```
